## 2. 分类性能

| 特征集 | 特征数 | LogReg macro-F1 | RF macro-F1 | RF agent 召回 |
|---|---|---|---|---|
| 仅延迟族 | 18 | 0.732 | 0.938 | 0.950 |
| ★纯行为集（判定依据） | 32 | 0.911 | 0.978 | 0.984 |
| 全部特征（含捷径，偏乐观） | 57 | 0.999 | 1.000 | 1.000 |

判定线：macro-F1 ≥ 0.7 且 agent 召回 ≥ 0.6 → GO


**本次判定依据：纯行为集** —— 全特征集含元特征/窗口特征/缺失模式三条捷径，用它判定会高估信号强度。


**延迟族单独贡献**：仅用 18 个延迟特征就达到 macro-F1 0.938，全部特征 1.000。差值 +0.062 —— 差值越小，说明延迟越是核心信号。


## 3. ★ 二分类对照实验（论文核心叙事）

用 human/bot 二分类器去分 agent 地址：

| 结果 | 占比 |
|---|---|
| agent → 被判为 **human** | **57.3%** |
| agent → 被判为 **bot** | 42.7% |

对标 Web 域 (arXiv 2607.26935)：MLP 二分类漏检 39.1%、SAINT 漏检 34.5%。

> 无论本实验数字高于还是低于 Web 域，都是可写进论文的结论：
> 高 → 链上问题更严重；低 → 链上 agent 更接近 bot，需解释为什么。

## 7. 本实验的已知局限（写论文时必须交代）

- **Δt 是代理量，不是真正的 event-response latency。** 链上无法历史回溯触发事件（HTTP 请求在链下、mempool 难回放）。完整版需引入 mempool 数据或合约事件配对。
- **人类样本有噪声。** CEX 提现地址只是弱先验，需做敏感性分析。
- **Olas 正样本量小但质量最高**，x402/ERC-8004 正样本量大但含大量空壳（实证：ERC-8004 仅 3–15% 有有效注册）。两者不可混用而不分层。
- **出块时间是分辨率下限。** Base 2s 出块意味着 <2s 的差异不可分辨；以太坊 12s 出块则完全无法区分 bot 与 agent 频带。
